# Benchmark results

`model_comparison.csv` is generated by `python scripts/benchmark_models.py` from the included reproducible 4H feature dataset.

Evaluation uses a chronological 80/20 split without shuffling. The target is next-candle direction. The test-period positive-class share is about 51.00%, so the reported ~52% accuracies represent only a small improvement over the class balance and should not be interpreted as evidence of trading profitability.
